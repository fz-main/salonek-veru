# Salonek Veru — сайт салона (Praha 7 – Holešovice)

Одностраничный сайт на React + TypeScript + Vite + Tailwind 4 + framer-motion.
Тёмная тема, фирменный акцент салона `#DFA378`. Языки: чешский и английский.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
npm run lint
```

## Где что менять

| Что | Файл |
| --- | --- |
| Цвет акцента | `src/index.css` → `--color-accent` |
| Контакты, соцсети, ссылка на карту, фото | `src/data/site.ts` |
| Услуги, цены, состав процедур | `src/data/services.ts` |
| Отзывы (Google Maps) | `src/data/reviews.ts` |
| Тексты интерфейса и «О нас» | `src/lib/i18n.ts` |

Новая услуга — новый объект в `SERVICES` (`src/data/services.ts`), тексты пишутся сразу на `cs` и `en`.

## Деплой

`vite.config.ts` использует `base: './'`, поэтому сборка работает из любой папки.
В репозитории есть workflow `.github/workflows/deploy.yml` — публикация на GitHub Pages при пуше в `main`
(Settings → Pages → Source: **GitHub Actions**). Свой домен пока не подключён.

## Заметки

- Фото сейчас подгружаются с `salonekveru.cz` (см. `SITE.images` в `src/data/site.ts`). Для боевого запуска лучше положить файлы в `public/` и заменить ссылки.
- Фоновое видео: `public/videos/bg.mp4` и `bg.webm` (~2,8 сек, видео салона от клиента: ускорено в 1,7 раза, конец обрезан). Запускается при первой прокрутке, доигрывает, затем размывается и затемняется, после чего появляются услуги. Чтобы заменить — положите свой файл с тем же именем. Если видео не загрузится, включается слайдшоу из фото.
- Фото салона и галерея лежат в `public/images/` (список и подписи — в `src/data/site.ts`). Чтобы добавить фото: положите файл в эту папку и добавьте строку в `gallery`.
- Записи через сайт нет: кнопки ведут на звонок мастеру, а для маникюра и педикюра — ещё и на онлайн-запись Notika (reservio).
- Оценка «5,0 · 25 recenzí» в `SITE.rating` / `SITE.reviewsCount` обновляется вручную.
